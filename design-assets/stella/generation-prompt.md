# Stella head atlas generation prompt

Built with the built-in image-editing workflow using the original Stella character sheet as the authoritative reference.

> Create one high-resolution transparent-background sprite atlas containing exactly eighteen isolated front-facing head-only renders of Stella in a strict 6-column by 3-row grid. Preserve Stella's pale peach soft-vinyl face, rounded designer-toy proportions, red cheek freckles, black plush hair material, minimal facial graphics, and premium studio-rendered finish. Use these columns in every row: Happy, Wink, Surprised, Cheeky, Sleepy, and Love. Use these hairstyle rows: Stella's original oversized plush bob; black plush twin space buns with straight bangs and a white star clip; and a short tousled black plush shag. Keep the face, head size, camera, crop, lighting, and facial-feature placement consistent. Include no torso, clothing, arms, legs, labels, borders, props, scenery, watermark, or signature. Use a genuinely transparent background and prioritize exact grid alignment and expression order.

The generator returned a visually rendered checkerboard rather than an alpha channel. The project therefore includes a cleaned transparent atlas, lossless PNG masters, and optimized WebP runtime sprites.
